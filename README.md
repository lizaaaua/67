Домашнее задание №2. Объектно-ориентированное программирование. Тестирование. Работа с Git.
В рамках домашнего задания разрабатывается программа для управления рецептами и списком покупок.
Реализованы следующие классы:
1.	Ingredient – представляет отдельный ингредиент (название, количество, единицы измерения). Поддерживает сравнение, строковое представление, защиту от отрицательного количества.
2.	Recipe – хранит рецепт блюда: название и список ингредиентов. Позволяет добавлять ингредиенты (с автоматическим объединением дубликатов), масштабировать порции, получать количество ингредиентов.
3.	DietaryRecipe – наследник Recipe с поддержкой диетических категорий (веган, без глютена и т.д.).
4.	ShoppingList – формирует общий список покупок из одного или нескольких рецептов, учитывая масштаб порций. Поддерживает добавление/удаление рецептов, объединение списков, группировку и суммирование одинаковых ингредиентов.
Все классы покрыты тестами с использованием pytest.
Использование
bash
# Клонирование репозитория
git clone <ваш-репозиторий>
cd <папка>
# Установка зависимостей
pip install -r requirements.txt
# Запуск тестов
pytest
